# Pizzería Mamma Mía - Hito 3

Catálogo dinámico y carrito local desarrollado con React, Vite y JavaScript.

## Funcionalidades

- Catálogo de seis pizzas renderizado con `map` y props.
- Ingredientes renderizados como elementos `li`.
- Carrito inicial basado en `pizzaCart`.
- Controles para aumentar y disminuir cantidades.
- Eliminación automática cuando una cantidad llega a cero.
- Total calculado automáticamente.
- Formularios de registro e inicio de sesión conservados del Hito 2.

## Instalación y ejecución

```bash
pnpm install --frozen-lockfile
pnpm dev
pnpm build
```
